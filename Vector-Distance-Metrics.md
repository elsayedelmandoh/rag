# Vector Distance Metrics

## Summary

Reference notes for vector similarity measures including cosine similarity, dot product, and Euclidean distance.

## Core formulas

- Cosine similarity: `cos(θ) = (A·B) / (||A|| ||B||)`
- Dot product: `A·B = Σ ai * bi`
- Euclidean distance: `||A-B||`

## Notes

Use cosine similarity when vectors are normalized and angular direction matters more than magnitude.
